# Contribuer

1. Forkez le dépôt puis créez une branche : `git checkout -b feature/ma-fonction`
2. Lancez l'app avec `npm start` et les tests avec `npm test`.
3. Gardez le projet **sans dépendance** : HTML, CSS et JavaScript natifs.
4. Ajoutez un test dans `test/` pour toute logique placée dans `src/chunker.js`.
5. Ouvrez une Pull Request qui décrit le changement et le navigateur testé.

Pistes : lecture depuis un point cliqué, file d'attente de textes, thèmes, interface en anglais.
